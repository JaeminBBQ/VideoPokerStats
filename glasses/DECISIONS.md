# Glasses decisions (append-only)

- **G1 (2026-10-16):** Target G2 + R1 ring via Even Hub (`@evenrealities/even_hub_sdk`). The owner has G2 + R1. G1 isn't supported.
- **G2 (2026-10-16):** Engine bundled into the Even Hub web app from `../src/engine/` (no server, no copy).
- **G3 (2026-10-16):** Glasses-local engine worker (`?worker&inline`) holds one game's tables in memory, and every built game's `sums` persist in IndexedDB, keyed on a hash of `src/engine/{ev,games,cards}.ts`. A first build takes ~0.85–5 s in desktop Chrome; a cached load takes ~10–20 ms. This matters because Android can kill the WebView between hands.
- **G4 (2026-10-16):** If no FOREGROUND_EXIT arrives after a cancelled exit dialog, any input ≥1.5 s after the exit request restores the page (`EXIT_STALE_MS`). This guards against a frozen glasses page on unverified firmware behavior.
- **G5 (2026-10-16, v0.2.0):** The phone is input only: game picker, suit-row card grid (♠ ♥ ♦ ♣ rows, A→2 across), Undo/Clear, and the letter-suits setting. The 5-slot row, result panel, and glasses preview are removed (owner's request); the hand and hold show only on the glasses. The default game is GSR Jacks or Better 9/5 (`gsr-job-9-5`), the owner's 5¢ game.
- **G6 (2026-10-16, v0.3.0):** Voice entry uses offline Vosk (vosk-browser 0.0.8), restricted to card words. The trimmed model (Gr.fst dropped, words.txt kept) is 27 MB in 2 parts on the owner's `vp-voice-model` Worker. It is downloaded once on request, sha256-verified, and cached in IndexedDB. The trigger is long-press on the ring or temple (9/10) using the glasses mic, and the hand is entered without a confirm step because the lens shows the parsed hand. Measured accuracy in reports/voice-v1.md: 96.3% hand-exact on 6 natural TTS voices.
- **G7 (2026-10-17, v0.4.0):** Ring code entry (CODE.md) replaces hold cycling on the glasses: tap / ↑ / ↓ pick a rank group, then rank, then suit, with double tap as select/back; the lens shows each step's gestures. Double tap no longer exits (the system's tap-then-hold does), so the `shutDownPageContainer(1)` path and G4's stale-dialog guard are gone; SYSTEM_EXIT/ABNORMAL_EXIT teardown and FOREGROUND handling stay. The input gate drops only true duplicates (same action ≤ 80 ms, `DUPLICATE_MS`), and raw event timing is logged at debug level for tuning on hardware.
- **G8 (2026-10-18, v0.5.0):** Discreet mode (Settings toggle, persisted as `vp.discreet`). It replaces the whole phone UI with a monochrome keypad: 13 rank keys (A→2, plus Jk on joker games), 4 suit keys, Undo, and a small "exit discreet mode" link. The owner taps the 5 ranks in dealt order and then the 5 suits in the same order. The phone never shows a card, only 5 progress dots; the lens reads the draft back (`K? Q? …`, then the pending card bracketed with "PHONE suit for Q card 2 of 5"). The last suit puts the hand through the same Entry path as taps. Undo on an empty draft reopens the 5th card's suit. Ring, voice, and tap entry still work, and any of them drops the draft. The game picker is hidden in discreet mode, so pick the game before turning it on. Also adds the missing lens short names for the T022a games, which had broken `tsc` and the short-names test.
